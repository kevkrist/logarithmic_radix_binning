# Logarithmic Radix Binning

This repository implements the **Logarithmic Radix Binning (LRB)** algorithm as introduced in the following paper:

> **James Fox, Alok Tripathy, Oded Green**  
> *Improving Scheduling for Irregular Applications with Logarithmic Radix Binning*  
> IEEE, 2020  
> [IEEE Xplore Link](https://ieeexplore.ieee.org/document/8916333)
